# GTM-Testseite „Tischlerei Beispiel“

Übungsseite für Google Tag Manager, GA4 und Conversion-Tracking.

- `site/` – die Testseite (wird auf Netlify veröffentlicht)
- `traffic/` – automatisierte Besuchstests der Seite (Playwright), Einstellungen in `konfiguration.json`
- `.github/workflows/testseiten-traffic.yml` – Zeitplan für die Besuchstests (Mo–Fr, 9–12 und 13–15 Uhr)

Alle Kontaktdaten sind fiktiv. Formulare werden bei den Tests im Browser abgefangen.
